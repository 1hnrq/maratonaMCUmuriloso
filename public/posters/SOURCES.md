# Poster artwork

The numbered images correspond to the existing, unchanged item IDs in `app.js` (0–36).
They are the theatrical/season poster thumbnails from the English Wikipedia articles
for the corresponding films and Loki seasons, retrieved on 2026-09-28 through the
MediaWiki PageImages API (`pilicense=any`). Artwork belongs to its respective rights
holders; this file does not grant a license to redistribute the posters.

Images are served locally as optimized JPEGs so visitors do not need to contact an
external image service. Keep this mapping aligned with the existing progress IDs.
